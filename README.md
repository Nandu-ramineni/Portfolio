# 🌐 Portfolio Website

A personal portfolio site built with **React + Vite**, showcasing projects, skills, and a contact form with EmailJS integration.

---

## 🚀 Tech Stack

- **React + Vite**
- **Tailwind CSS**
- **Framer Motion** (animations)
- **EmailJS** (contact form emails)
- **Sonner** (toast notifications)
- **Lucide / HugeIcons** (icons)

---

## ✨ Features

- 📌 Home, About, Projects, and Contact sections  
- ⚡ Smooth animations & hover effects  
- 📧 Contact form with EmailJS integration  
- 🔔 Success/Error notifications with Sonner  
- 📱 Fully responsive design  

---

## 🛠️ Installation & Setup

1. Clone the repository:
   ```bash
   git clone https://github.com/Nandu-ramineni/Portfolio.git
   cd Portfolio
````

2. Install dependencies:

   ```bash
   npm install
   ```

3. Create a `.env` file in the root:

   ```env
   VITE_SERVICE_ID=your_emailjs_service_id
   VITE_TEMPLATE_ID=your_emailjs_template_id
   VITE_USER_ID=your_emailjs_public_key
   ```

4. Run the development server:

   ```bash
   npm run dev
   ```

5. Open in browser:

   ```
   http://localhost:5173
   ```

---

## 📧 Contact Form (EmailJS)

* Sends form submissions via EmailJS
* Shows animated loader while sending
* Displays success/error toast feedback

Make sure your EmailJS template uses variables: `name`, `email`, `subject`, `message`.
